# Anixweb

> Это неофициальный клиент, не связанный с разработчиками Anixart. Некоторые функции могут отсутствовать, а дальнейшая поддержка и разработка не гарантируются.

Anixweb — неофициальный веб-клиент мобильного приложения Anixart с открытым исходным кодом.

> Данный проект находится в раннем этапе разработки, большинство функций на данный момент отсутствует.

## Что работает:
  - [ ] Аккаунт
    - [x] Вход, регистрация аккаунта и восстановление пароля
    - [x] Просмотр своего/чужого аккаунта
    - [ ] Редактирование данных аккаунта
  - [x] Главная страница
    - [x] Вкладка "Моя вкладка"
    - [x] Вкладка "Последнее"
    - [x] Вкладка "Онгоинги"
    - [x] Вкладка "Анонсы"
    - [x] Вкладка "Завершенные"
    - [x] Вкладка "Фильмы"
  - [x] Поиск
  - [ ] Просмотр аниме по фильтрам
  - [x] Смена темы (приложение оптимизировано для светлой темы, полная работоспособность темной темы не гарантирована)
  - [x] Страница релиза
    - [x] Добавление в списки/избранное
    - [x] Просмотр серий
    - [x] Кадры
    - [x] Комментарии
      - [x] Лайк/дизлайк коментарию[^*]
      - [x] Возможность ответить на коментарий[^*]
      - [x] Возможность оставить коментарий[^*]
      - [ ] Все комментарии
      - [x] Просмотр ответов  
  - [x] Встроенный плеер
    - [x] Сохранение времени просмотра
    - [ ] Смена качества
    - [ ] Улучшение качества с помощью [Anime4K](https://github.com/bloc97/anime4k)
    - [ ] Смена скорости
    - [ ] Смена соотношения сторон
  - [x] Просмотр истории/избранного/списков
  - [x] Случайное аниме

  [^*]: Работа данных функций в будущем не гарантирована

## Локальная сборка
  ```bash
    git clone https://github.com/imnottimaq/anixart-web.git
    cd anixart-web
    npm install
    // для сборки сайта
    npm run build
    // для запуска локального dev-сервера
    npm run dev
  ```
